A portfolio of applied economic research in financial markets and urban economics, using R, econometric methods, data visualization, and policy interpretation.

## Projects

| Project | Focus | Materials |
|---|---|---|
| [The Trade Desk vs. S&P 500](trade-desk-market-analysis/README.md) | Descriptive analysis of equity prices and the broad market, 2021–2026 | Original R Markdown, model discussion, reproduction notes |
| [La Boca & San Telmo, Buenos Aires](buenos-aires-urban-economics/README.md) | Tourism, transit access, historic preservation, urban land use, and short-term rentals | Joint research summary and presentation notes |

## Methods and tools

- **Programming:** R, RStudio, R Markdown, tidyverse, ggplot2
- **Analysis:** exploratory data analysis, linear and polynomial regression, LOESS, model comparison, time-series visualization, spatial distance calculations
- **Communication:** economic research presentations, technical writing, and policy-oriented interpretation

## About this work

These projects were completed as part of undergraduate coursework and university research experiences. The Trade Desk source is a cleaned, lightly edited version of coursework, and its output has **not been independently rerun** for this repository. It is descriptive analysis, **not investment advice**.

The Buenos Aires research is jointly authored by **Zenah Itani and Sachhyam Manandhar**. The original project data and R scripts are not included in the available source materials, so its reported estimates cannot be reproduced from this repository alone. See each project's README for limitations.
